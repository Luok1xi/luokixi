# 上网、资料缓存与识图升级

这次将 LifeCodex 文档中“能力不等于意图”和“工具结果要可验证”的原则落到现有系统；没有把整篇架构宣称为已实现，也没有加入自主改写核心代码。

## 如何用

- 对话框可附加一张 PNG、JPEG、GIF 或 WebP，最多 8MB；微信私聊也接收单张图片。先由 DeepSeek Flash 观察图片，再由原有 Miku 表达流程结合上下文回复。识别结果有缓存，重复图片不会重复做视觉调用。文字回复仍使用已配置的模型。
- 在聊天页下方展开“上网与资料工具”，可打开 B站、知乎、niconico 的专用登录窗口。自行登录/验证后点击“登录完成”。这只解除读取冷却，下一次实际访问才判断是否成功。登录资料只在本机 `data/web-browser` 中，不读取其他浏览器的账号。
- 可以说“读一下 https://…”，或“下载这份资料 https://…”。意图提取选择只读工具，网址必须出现在本次消息中；工具结果交给同一个 Miku 写回复。论文搜索使用已有 arXiv 接口，不额外接 OpenAI。
- 自主阅读成功取得的正文自动存为本机文本资料，可在工具面板下载或删除缓存。PDF、图片、纯文本的直接下载限制单份 8MB、每天 20 份、总量 100MB；同网址一天内复用，内容哈希去重。资料只保存，不自动执行，也不安装网上的脚本或技能。
- 新浏览器通道已接入原来的自主浏览与日记流程。重试失败不会自动记成学会了；登录或验证码状态会让浏览器暂停自动尝试一小时。网站明确禁止的抓取不走备用通道。

## GitHub 与官方资料

- [browser-use](https://github.com/browser-use/browser-use)：参考持久浏览器会话与工具观察的组织方式；没有安装其整个 Agent 或云浏览器。
- [Crawl4AI](https://github.com/unclecode/crawl4ai)：调研其抓取、缓存、提取分层，当前继续复用本项目 Readability/结构化适配器。
- [Playwright](https://playwright.dev/docs/auth)：实际复用本机已有 Playwright 和 Edge，增加独立持久配置目录。没有安装 Node.js/npm，也没有下载浏览器。其他电脑需自行提供 Playwright 与 Edge。
- [腾讯微信协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)：按协议下载/解密接收到的微信图片，支持两种 AES key 编码；媒体密钥不进入模型上下文。
- [DeepSeek 图像理解](https://api-docs.deepseek.com/guides/vision/)：使用现有 Flash 视觉路由，按官方图像 token 上限修正预算预留；实际调用仍进总预算账本。

## 已验证与限制

2026-09-21 实测：

- 真实 Flash 识别合成测试图的红色方块和文字 `MIKU 314`，一次费用约 0.00098 元。
- B站公开搜索接口返回 HTTP 412，浏览器后备通道取得 8 条搜索结果，并读到一条机器人视频约 1050 字的介绍。记录类型是视频介绍，不是完整视频。
- 知乎公开搜索返回 HTTP 400，浏览器显示安全验证。**尚未完成用户登录后的真实验收**；不声称已经解决知乎访问。
- 公网下载器实际下载并验证了 Playwright 的公开 LICENSE 文本。
- 微信加密入站图片、重复消息、共用写作流程以协议测试验证；**真实手机发图到回复仍需设备验收**。
- 桌面图片上传→观察→同一回复流程、移动端入口可见性均通过浏览器自动化验证。

没有接通 B站站内 AI 总结、任意视频画面理解或通用自动操作一切网站。新工具不会自动绕过验证码、付费墙或权限限制；没有声称修改了模型权重。表情包仍由模型自主选择，但删除了鼓励重复刷屏的提示，不用固定台词替代模型。

运行检查：`node --test test/*.test.mjs`，`node test/tools-browser.mjs`。真实付费验证脚本需显式传 `--paid-check`，记录在 `test-output`，不打入源码包。
