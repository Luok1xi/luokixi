# 2026-09-21：实际爬虫、问题追踪与 Miku 表情

## 本轮实际安装

安装 `@crawlee/basic@3.18.1` 到 `tools/crawler`，锁定依赖并禁用安装脚本。没有安装新的 Node、npm、Python、浏览器或常驻服务。

筛选了 [Crawlee](https://github.com/apify/crawlee)（查验时 25,860 stars）、[Crawl4AI](https://github.com/unclecode/crawl4ai)（84,027 stars）及 [Scrapling](https://github.com/D4Vinci/Scrapling)。选择 Crawlee 是因为它能直接接入现有 Node 和浏览器链路，避免另起一套 Python 服务；不是因为它星数最高。

运行中的阅读路径：聊天/自主阅读/课程学习 → Crawlee BasicCrawler → 现有公开读取器或专用浏览器。实际使用请求去重、最多两路并发、每批最多四个链接、瞬态失败最多重试一次。访问拒绝、验证码和抓取规则拒绝不重试。读取成功后缓存一小时，最多 120 条，跨重启复用；清理记忆使在途旧结果失效。基础请求队列不保证进程崩溃后继续执行，已有业务记录会标明中断。

`read_many` 比较多个用户提供的链接，保留每条链接的成功/失败；`search` 检索 B 站、知乎、niconico；`research` 只继续读取真实搜索结果。网页和评论不能授权执行程序或改动私人状态。Crawlee 没有神奇地消除网站登录和验证码。

## 按 LifeCodex 建立问题闭环

新增 `Inquiry`：真实学习笔记的未解问题 → 模型选题/公开关键词 → 论文搜索 → 选择最多两篇真实结果 → 批量阅读 → 选择原文证据编号 → 核对新理解 → 保存后续问题和待验证用法。检索过窄时最多放宽一次，并遵守接口间隔。没有资料或核对失败不记为学会，也不关闭原问题。

每日最多一次问题追踪，计入原学习预算；暂停、免打扰、清理操作均生效。问题追踪结果进入现有见闻笔记，由同一个聊天写作模型决定如何分享。不会直接把研究报告推给用户。清理见闻不退还当天尝试次数。

自主活动普通间隔调整为 90 分钟；有新问题可在 60 分钟后判断，失败后等待 180 分钟。判断不等于发消息，原每日活动数、消息批次数、静默和预算限制继续生效。课程选择可看到真实诊断分数和学习优先级。

借鉴 [MAGELLAN / ICML 2025](https://proceedings.mlr.press/v267/gaven25a.html) 的进展驱动选题思路和 [ToolMaker / ACL 2025](https://aclanthology.org/2025.acl-long.1266/) 的执行反馈验证思路。这是本地工程应用，**没有复现论文训练、修改模型权重，也没有把阅读笔记当作已安装工具**。本轮 Crawlee 是实际安装和运行的工具。
