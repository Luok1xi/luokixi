# Miku 微信接入与进阶使用

2026-09-21：微信已支持连续文字和真实表情图片发送，由模型决定分段。当前规则与测试结果见 [CONVERSATION-UNIFICATION.md](CONVERSATION-UNIFICATION.md)。接收侧仍以文字为主，不表示已支持识别手机发来的图片和语音。

更新：2026-09-19。适用于本项目与 iPhone 微信。电脑入口：http://127.0.0.1:17839/

## 先认识这次接入

微信现在是 Miku 的消息入口。电脑端、微信端和原有飞书端使用同一个本地服务，任务、课程、聊天、记忆和角色状态共用。

本版依据腾讯公开的 iLink 协议实现文字适配层，没有另外安装 OpenClaw，也没有把另一套 OpenClaw 人格替换进来。DeepSeek 仍负责理解与表达，程序不增加固定社交台词。Windows 电脑运行 Node.js 服务，手机微信负责聊天。

官方插件还支持媒体等能力；本次移植先提供文字私聊与现有日程提醒。图片、PDF 课表继续在电脑端导入。本版不读其他好友聊天、不进群、不操作朋友圈、不使用微信电脑版注入或第三方收费中转。

## iPhone 首次连接

1. 运行项目中的“启动Miku.cmd”，打开电脑控制台，进入“连接与设置”。
2. 在“在微信里和 Miku 说话”卡片中点击“生成微信登录二维码”。
3. 用你自己的 iPhone 微信“扫一扫”扫描电脑上的二维码，并在手机确认授权。不要将二维码转发给其他人：扫码账号将成为本机助手的使用者。
4. 若手机显示数字配对验证码，把它填入电脑页面出现的验证码框。输入的是手机显示的配对码，不是微信密码，也不需要提供密码给助手。
5. 授权成功后，在手机新出现的 ClawBot/相关插件对话里发一条文字，例如“你好”。入口名称与位置以你实际微信版本显示为准。
6. 电脑状态出现“微信已连接”后，点击“向我的微信发送测试”。必须在手机真正收到消息，才完成发送方向验收。
7. 再从手机发“今天有什么安排”，确认收到回复，并在电脑对话页看到同一段交流。

二维码约五分钟有效，过期重新生成。刷新网页可以恢复当前有效二维码。如果扫码提示客户端不支持，先更新 iPhone 微信，再查看“我 → 设置 → 插件”中的相关入口；是否对该账号开放，以微信实际授权结果为准。

不需要再申请模型密钥，也不需要购买域名或把本机网页暴露到公网。获取二维码不调用大模型；聊天和资料学习继续计入原来的月度预算。

## 第一轮实际使用练习

按顺序尝试，不要一次把所有内容塞入一句话。

### 1. 先设置真实生活约束

电脑端录入学期第一周、单双周课程、教室、通勤和作息。微信只是入口，无法凭空知道当前位置，也不会自动读取系统日历。课表识别仍需确认。

### 2. 给一项真实任务完整信息

例如：“添加高数第三章作业，9月21日晚上10点截止，还需要120分钟，可以分开做，重要程度高。”

检查电脑“待办”页是否只有一条新任务、时间是否正确。缺少会影响安排的信息时，模型可以追问。不要用是否回复“记住了”来判断成功，以任务数据和执行结果为准。

### 3. 汇报变化，观察自动重排

- “高数第三章作业还需要两小时”：应把剩余时间更新为120分钟，不是加120分钟。
- “今天不想学了”：将今天剩下的弹性任务向后调整，固定课程与截止时间不擅自改变。
- “高数第三章作业完成了”：仅明确完成才减少待办，时间过去不会自动算完成。

固定安排和截止时间修改会生成确认提议。只有一项提议时可回复“确认”；有多项时到电脑页面选择。撤销排程目前以电脑“今日与计划 → 撤销上次排程”为准，撤销仍检查是否有新进度或冲突。

### 4. 把长期事实与临时心情分开

可以明确说“记住，我更喜欢下午处理需要专注的任务”，随后在电脑“记忆”页核对来源与确认状态。风格反馈由模型结合上下文理解；短暂烦恼不应自动变成永久性格标签。

纠正或删除记忆建议在电脑端操作，能看到究竟删了哪条。删除会清理本地相关聊天与摘要；已经送达手机微信的消息不会被本机自动撤回。

### 5. 让她认真分析，但别把聊天与执行混为一谈

例如：“认真比较我先学控制理论还是先做一个小机器人项目，结合现有课表和时间。”模型会自行判断思考方式。微信端没有额外写死的深度模式命令；需要强制指定本轮方式时使用电脑端下拉框。

如果希望她只听你说，可以明确表达。她的回应来自模型，不会为了贴合例句而被程序替换。微信通道不会让模型凭空增加联网能力；实时查询是否可用，仍取决于资料工具配置。

## 主动提醒怎样工作

早晨计划、课前出发、任务时段和截止事项使用原来的持久队列。普通主动聊天仍受原有频率限制；免打扰、每日上限、合并过期提醒等规则同时适用于微信。

需要同时满足：电脑开机、未休眠、联网、Miku 服务运行、微信授权有效、有有效会话上下文。

腾讯协议客户端建议回复时携带收到消息里的 context_token，公开说明不能保证服务端接受缺少凭证的发送。官方仓库也记录过凭证过期导致 HTTP 200 但业务拒收的问题。因此本版遇到 -2 会暂停发送，提示你从微信发一条新消息；收到新消息后恢复尝试。遇到 -14 则要求重新扫码。没有将未经设备验证的“永久主动推送”当成功能承诺。

本机“发送成功”表示微信接口明确返回成功，不代表 iPhone 已显示横幅或你已阅读。还要检查 iPhone 的微信通知权限、微信内消息免打扰和专注模式。长回复会按传输长度分段，正文不改写。

断网恢复后只发送仍有效的提醒；旧消息不会集中补处理。超过两小时的入站消息会失效，防止突然执行很久以前的指令。换绑账号会取消旧绑定未发送的消息，已过时提醒不会迁移给新绑定。

## 常见情况

| 页面或手机现象 | 应对方式 |
| --- | --- |
| 找不到 ClawBot/扫码不支持 | 更新微信并查看插件页；记录手机具体提示。账号可用性以实际授权为准，不保证所有版本同时开放。 |
| 已授权，但测试按钮不可用 | 先在手机给插件发送一条新文字，等待会话建立。 |
| 微信网络连接失败 | 确认电脑能访问微信服务，再重试。无需更改 VPN 或公开本机端口。 |
| 会话凭证失效 | 从手机发新消息；若仍不恢复，再重新扫码。 |
| 授权已失效 | 重新扫码，并确认没有在另一实例同时使用同一个 Bot 凭证。 |
| 手机上无回复 | 先看电脑是否收到聊天，再查模型连接、预算和微信状态。消息刚发送后，处理与发送可能需要数十秒。 |
| 电脑显示发送成功，手机不弹通知 | 打开插件对话检查实际内容；再检查通知、免打扰、专注模式。 |
| 收不到图片/文件内容 | 当前移植版只支持文字，不会假装看懂媒体；请在电脑端导入。 |
| 回复自然度不理想 | 这是模型、人格背景及上下文的问题；不要添加固定句子替换。微信接入本身不改变模型。 |

## 数据与维护

- 登录凭证、会话上下文和游标存于本机 SQLite 的独立私有表，不进入模型提示词、普通数据导出或源代码压缩包。
- 断开按钮会删除本机微信凭证并取消待发消息。需要彻底撤销微信端授权时，另在手机相关插件管理中解除。
- 不要把 data 文件夹、.env、数据库或二维码上传到 GitHub。普通“导出我的数据”用于查看业务数据，不包含可恢复微信登录的凭证。
- 修改程序前保留源码副本；如要备份整个 data 文件夹，应先停止 Miku 再复制到自己控制的位置。数据库包含私人对话，完整数据库备份还包含登录凭证。
- 电脑关机后不能继续主动联系。当前没有自动安装开机服务或云部署。

## GitHub 上有哪些方案，怎样判断

| 仓库 | 实际入口 | 本次判断 |
| --- | --- | --- |
| [Tencent/openclaw-weixin](https://github.com/Tencent/openclaw-weixin) | 微信扫码授权，iLink 收发 | 本次主要依据，阅读了官方协议与登录流程。 |
| [WecomTeam/wecom-openclaw-plugin](https://github.com/WecomTeam/wecom-openclaw-plugin) | 企业微信 | 适合企业微信工作流，不能当成个人微信入口的同义词。 |
| [dingxiang-me/OpenClaw-Wechat](https://github.com/dingxiang-me/OpenClaw-Wechat) | 企业微信应用、机器人等 | 社区方案，配置和账号前提需要分别核对。 |
| [freestylefly/openclaw-wechat](https://github.com/freestylefly/openclaw-wechat) | 依赖 API Key 与代理服务的接入 | README 列有第三方接入条件，本次没有安装或购买。 |

读项目时，先看 README 的前提条件和架构，再看 Issues 中是否存在你需要的主动推送、断线恢复、账号限制问题。名字写 WeChat 不等于在个人微信原生对话里收发，也不等于具备其他好友/群聊读取权限。Star 数不能替代账号实测。

GitHub 使用建议：收藏主仓库；关注 Releases 获取更新；在 Issues 搜索报错代码、系统和版本；查看改动涉及哪些权限与数据；测试后再更新。需要维护自己的改版时可以 Fork，但请只上传不含密钥和私人数据的源码。本次没有替你注册账号、Fork、推送或发布任何文件。

如果以后想独立体验 OpenClaw，官方 README 当前列出的流程是安装 OpenClaw 后安装 @tencent-weixin/openclaw-weixin、执行 channels login、重启并检查网关。那将是另一套运行环境，不能直接替换当前 Miku。不要同时启动两个客户端消费同一个微信 Bot 的消息。
