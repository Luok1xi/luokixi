# 检索与科研：技能化工具升级（2026-10-06）

这一轮的目标是让 Miku 更会用工具：查得更准、查得更快，并且能做科研调研。人格、记忆和说话方式没有改；查到的资料仍由 Miku 本人组织语言后告诉你。

## 改了什么

| 以前 | 现在 |
| --- | --- |
| 每轮最多调用 1 次工具，不能"搜完再读、读完再搜" | 检索执行器最多跑 6 轮（研究项目最多 26 轮），一轮里可以并行调用多个工具 |
| 只能搜 B站 / 知乎 / niconico 和 arXiv | 加上维基百科、OpenAlex、Europe PMC、Crossref、Semantic Scholar、引用网络、GitHub、StackOverflow、Hacker News，以及可选的通用网页搜索 |
| 论文只读摘要 | 能读开放获取全文（PDF / PMC）。付费墙论文会自动找 arXiv 版本，按问题返回最相关的段落 |
| 回答没有逐条出处 | 每个结论带编号（S1 网页 / P1 论文），引文逐字核对原文，核对不上会标出来 |
| 没有科研流程 | 后台研究项目：拆子问题 → 检索 → 精读 → 综合，生成带参考文献的报告，可导出 Markdown / BibTeX |

## "技能"是什么

`skills/` 文件夹里每个子文件夹放一个 `SKILL.md`，格式和 Claude 的 Skill 一样。开头写名字、适用场景（description）和触发词（keywords），正文写具体做法：先查哪里、检索词怎么写、读几篇、什么时候停、怎么交结论。

平时执行器只看到技能的名字和一句话说明；接到任务时先选出匹配的技能，再加载全文照着做。选择方式有两层：先由对话路由直接点名，点不出来再按触发词匹配。

| 技能 | 用在什么时候 |
| --- | --- |
| web-research | 一般信息查询：规则、价格、报名、地点、对比 |
| fact-check | 核实传闻、说法、数据是不是真的 |
| news-tracking | 最新动态、发布、比赛结果 |
| paper-search | 找论文、查出处、看某研究的方法和结论 |
| literature-review | 科研调研、文献综述、课题前期调研（研究项目默认用它） |
| tech-research | 报错排查、开源项目和框架选型 |
| learn-concept | 理解一个概念或原理 |

想加新技能：在 `skills/` 下新建一个文件夹，放入同样格式的 `SKILL.md`，保存后下一次检索自动生效，不用重启。技能只能规定"怎么用现有工具"，不能增加权限、访问新网址或执行程序。

## 怎么用

- **在对话里**：直接问需要资料的问题，比如「ORB-SLAM3 比 ORB-SLAM2 多了什么，给出论文出处」。聊天框上方会实时显示检索到第几步；回答末尾附带参考来源。
- **深入研究**：说「帮我深入研究一下……」「做个文献综述」，研究会在后台进行。完成后 Miku 会在聊天里告诉你；如果是从微信发起的，就回到微信。
- **资料与目标 → 检索与科研**面板：
  - 开始研究项目，查看进度和报告，导出 Markdown / BibTeX
  - 「快速检索测试」：直接查看每一步调用了什么、读了哪些来源、花了多少钱
  - 填写搜索服务 Key，设置花费上限
  - 查看技能列表和工具的真实成功率

## 搜索服务 Key（需要你选一个）

学术库、维基、GitHub、StackOverflow 不需要 Key，已经可以用。**通用网页搜索**（新闻、官网、政策、价格）需要一个 Key：

- **Tavily**：每月 1000 次免费，英文和国际资料较好。到 tavily.com 注册即可。
- **博查**：中文网页和新闻较好，按次计费。
- Brave、自建 SearXNG：可选。

Key 只保存在本机 `data/config.json`，网页不会回显。没填 Key 时，执行器看不到网页搜索工具，不会白白浪费一次调用，也不会假装上网查过。

## 费用

所有模型调用都计入原来的每月 200 元预算。
- 对话中的一次检索：默认上限 ¥0.4，实测约 ¥0.1。
- 一个研究项目：默认上限 ¥2。

快到上限时执行器会停止检索，用已有资料交结论。两个上限都可以在面板里调整。

## 实测结果（2026-10-06，真实 DeepSeek + 真实接口）

问题：「ORB-SLAM3 相比 ORB-SLAM2 主要增加了哪些能力？请给出论文出处。」

| | 第一版 | 优化后 |
| --- | --- | --- |
| 用时 | 108.7 秒 | 24.0 秒 |
| 工具调用 | 9 次（含 1 次无效的网页搜索） | 6 次 |
| 费用 | ¥0.158 | ¥0.101 |
| 使用技能 | 没有 | paper-search |
| 引文逐字核对 | 3/5 | 4/4 |
| 来源 | 只有 ORB-SLAM3 论文摘要 | ORB-SLAM3 和 ORB-SLAM2 两篇原论文 |

针对实测发现的问题做了 4 处修复，之后重新验证：
- 按引用数排序时先保证相关性
- 在同一次任务里复用已读过的全文
- 付费墙论文自动找 arXiv 版本：ORB-SLAM3 读到 18 页全文
- 修复新版 pdf.js 释放资源时报错

另外，DeepSeek 在普通模式和思考模式下的工具调用格式都已实测通过（思考模式需要回传推理内容）。

免费接口实测 13/14 项成功：维基、OpenAlex、Europe PMC、Crossref、arXiv、论文详情、引用网络、论文全文、GitHub、StackOverflow、Hacker News、网页精读。唯一失败的是网页搜索，因为还没填 Key。

## 还没验证的

- 填写 Tavily / 博查 Key 后的真实网页搜索效果。
- 用真实模型完整跑一个后台研究项目（26 轮上限）的质量和费用，目前只用模拟模型验证了流程。
- 研究完成后通过微信送达手机。
- 引文"未能逐字核对"不代表结论错，可能是模型改写了措辞，请回原文确认；"已核对"只说明引文确实出现在原文里，不代表结论本身一定正确。
