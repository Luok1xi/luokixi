# 学习一个概念

## 1. 定义与定位
- 并行：wiki_search(zh) + wiki_search(en)。英文条目常常更完整、更准确。
- 用 read_page 读最相关条目中的定义和原理部分（focus 写「定义 原理」或用户关心的方面）。

## 2. 补充深度（按需选择一种）
- 数学/统计/物理推导：qa_search（math / stats / physics）找经典解释。
- 学科前沿或应用：scholar_search（openalex，reviews_only）找一篇综述的摘要。
- 工程实践：web_search 找官方文档或教材性质的页面。

## 3. 比较类问题（XX 和 YY 的区别）
- 分别检索两者的定义，再找直接对比的来源。
- 从这些维度比较：目标、原理、适用条件、优缺点、典型例子。

## 4. 提交
- answer 结构：一句话定义 → 核心原理（直观解释）→ 一个具体例子 → 常见误区或适用边界。
- 定义和关键公式、数字必须来自来源（带编号）；用来帮助理解的类比可以自己写，但不要标成来源结论。
- followups：建议接下来学的 1—3 个相关概念。
