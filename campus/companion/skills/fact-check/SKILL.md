# 核实说法

## 1. 拆成可检验的子命题
- 把原说法拆成 1—4 个独立事实：谁、做了什么、何时、数字是多少、出处是哪里。
- 标出最关键、最容易出错的那一个（通常是数字、日期或引语）。

## 2. 找一手来源
- 优先找原始出处：官方公告、政府/机构网站、论文原文、当事人账号、原始报道。
- 并行检索：「原说法中的关键实体 + 关键数字/关键词」以及「实体 + 辟谣 / 回应 / 官方」。
- 涉及科学或健康结论时，用 scholar_search 查综述（reviews_only）或权威机构页面。

## 3. 精读与比对
- 用 read_page 读原文，focus 写成要核对的具体子命题。
- 核对：时间是否对得上；数字的单位和口径；引语是否被截断或断章取义；是否把旧闻当新闻。
- 二手转载互相引用不算独立证据；要追溯到同一个源头。

## 4. 给出判定
每个子命题给出：属实 / 部分属实 / 不实 / 无法确认，并附依据。
- 「无法确认」不是「不实」：找不到证据时如实说明。
- answer 先给总体判定，再逐条说明；findings 每条附原文逐字片段。
- gaps 写出还缺什么证据。
