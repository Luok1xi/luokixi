# 最新动态

## 1. 确定时间窗
- 以今天日期为准，判断用户要的范围：今天/本周 → freshness=day 或 week；最近一两个月 → month。
- 没有时效词但话题明显随时间变化（价格、赛况、版本），也加 freshness=month。

## 2. 检索（并行）
- 「实体 + 事件关键词」+「实体 + 官方/公告/发布」；国际话题同时用英文查询。
- 技术产品更新：同时查官方博客/更新日志（site 限定官网）和 hackernews。
- 国内社区反应：community_search zhihu / bilibili（只作为反应，不作为事实来源）。

## 3. 核对日期
- 每条结果先看发布日期；没有日期的页面要读原文确认。
- 用 read_page 读 1—3 篇最新、最权威的报道或官方原文。
- 早先报道与最新消息冲突时，以最新的官方信息为准，并说明变化过程。

## 4. 提交
- answer 按时间顺序写：最新状态（日期）→ 关键经过 → 尚未确定的部分。
- 每个事实标来源编号和日期；传闻、爆料明确标为未证实。
