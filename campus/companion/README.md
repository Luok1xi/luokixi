## 新电脑快速开始

需要 Node.js 24+。在项目目录执行：

    npm install
    npm --prefix tools/crawler ci
    npm start

然后访问 http://127.0.0.1:17839 。在本地设置界面配置自己的模型连接；可选环境变量模板为 [.env.example](.env.example)。没有密钥时，不会因此具备模型对话能力。

当前启动与测试会导入 Crawlee，因此 tools/crawler 的依赖也必须安装。QQ/微信外部读取工具需另行安装和配置，见 [EXTERNAL_RUNTIMES.md](tools/EXTERNAL_RUNTIMES.md)。

    npm test

本次未上传 data、聊天与研究缓存、NapCat 安装副本、账号二维码、Cookie、密钥或浏览器会话。开始使用时创建自己的本机数据。第三方素材与代码保留 [原许可和署名](THIRD-PARTY-NOTICES.md)，不宣称都是自创内容。

## 在这台电脑开始使用

1. 双击本目录的 **启动Miku.cmd**，浏览器会打开 **http://127.0.0.1:17839**。本机依赖已安装。
2. 进入 **连接与设置 → 连接模型**，填写你自己的 DeepSeek API Key，保存后点击 **小额测试连接**。密钥在本机填写，不需要发到聊天里。
3. 月预算默认 **200 元**，也可以先调低试用。OpenAI 默认关闭，DeepSeek 可以独立工作。
4. 修改 **学期第一周的星期一** 和作息。默认日期只是起始设置，不是你的真实校历。
5. 先录入一门真实课程和一项真实待办，再到对话页试一下「高数还需要两小时」或「今天不想学了」。

关闭浏览器后服务仍可运行；双击 **停止Miku.cmd** 才会停止本地服务。没有安装开机启动服务。电脑关机、休眠或断网时不能保证按时送达提醒。

没有模型密钥时，课表、任务、排程、进度、记忆管理及提醒队列都可操作。少量明确指令可在本地处理，但这不等于已连接 AI 自然对话。

## 飞书手机入口

使用企业自建应用的官方长连接方式，不需要公网服务器或公开网页。具体账号是否有创建和发布应用权限，需要在你的飞书组织中确认。长连接方式见 [飞书官方 Node SDK](https://github.com/larksuite/node-sdk)。

1. 在 [飞书开发者后台](https://open.feishu.cn/app) 创建企业自建应用，开启 **机器人** 能力。
2. 在权限管理中申请读取发给机器人的单聊消息、以应用身份发送消息。对应常见权限标识为 `im:message.p2p_msg:readonly`、`im:message:send_as_bot`；以后台展示及事件所需权限为准，不需要申请群聊全量读取权限。
3. 把应用的 **App ID / App Secret** 填入本地控制台的飞书设置，勾选启用，点击 **保存并连接**。这一步让本机先建立长连接。
4. 在开放平台 **事件与回调** 中选择 **使用长连接接收事件**，订阅 `im.message.receive_v1`；需要卡片上的「完成了」按钮时，同时配置 `card.action.trigger` 回调。参阅 [官方接收消息事件文档](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive) 与 [SDK 事件处理说明](https://github.com/larksuite/node-sdk)。
5. 创建版本并发布，应用可用范围只加入你自己；组织有审批流程时先完成审批。
6. 本地点击 **生成绑定码**，从手机飞书私聊机器人发送显示的「绑定 六位数字」。绑定码有效期 10 分钟。第一次绑定后，只接受这个用户的私聊文字与相应按钮操作。
7. 点击本地 **发送测试消息**，以手机实际收到为准。回复「你好」，再从手机更新一项任务，在电脑查看是否同步。

保存凭证或显示「已启动长连接」不能证明手机通知正常。收不到时依次核对：本机服务正在运行、应用已发布、自己在可用范围中、事件与权限已开通、账号已绑定，以及飞书通知与手机系统通知设置。

V1 飞书入口处理私聊文字；图片/PDF 课表请从电脑控制台上传。超过两小时的延迟消息不会在恢复后重新执行，避免把昨天的「今天休息」误用于今天。请重新发送仍需处理的指令。

## 日常使用

| 事情 | 操作 |
| --- | --- |
| 建立任务 | 提供名称、剩余工时和截止时间，或使用待办表单 |
| 剩余时间变多 | 「高数还需要两小时」将剩余值改为 120 分钟，不是再加 120 分钟 |
| 汇报进度 | 待办里点击「记录进度」，分别填写实际用时和当前剩余时间 |
| 完成 | 明确说完成、使用「完成了」按钮；时间过去不会自动扣工时 |
| 今天想休息 | 尚未开始的弹性时段往后移动；日程页显示变化和排不下的工作 |
| 固定安排/截止日期变更 | 在表单明确修改，或确认聊天提出的具体变更提议 |
| 撤销 | 「今日与计划 → 撤销上次排程」；已有新进度、冲突或旧时段已过去时，会拒绝直接回滚 |
| 课表识别 | 上传 PNG/JPEG/WebP/PDF，先核对草稿，再点击导入；缺少节次时间表时需要补充，不会猜时间 |
| 记忆更正/删除 | 记忆页操作；同步清理近期对话、摘要、关联剧情、称呼和未解决冲突文字，关系阶段保留 |
| 暂停角色关系 | 「相处 → 暂停角色互动」，普通助理功能继续工作 |

所有时间使用北京时间。课表支持起止周、单双周、单次停课、教室及课前/课后通勤预留。没有实时定位，通勤是你填写的预估值。

排程按截止时间优先、同截止时间按重要程度分配。默认规划未来 14 天，每天弹性学习上限 300 分钟、单次 90 分钟、间隔休息 10 分钟；可在设置里修改。睡眠、用餐、课程及固定安排优先占用时间。默认用餐为 07:15–07:40、12:00–12:40、18:00–18:40；本版用餐时间在 `src/planner.mjs` 的默认设置中定义，尚未提供界面编辑。

规划器会尽量保留有效的旧安排，并明确展示未排入的工时。它是确定性启发式规划器，不保证找到全局最优解。进入当前时段后会优先保留该时段剩余部分，但「时段已开始」不代表用户已开始或完成任务；工时仍以你的汇报为准。发生新的固定冲突会显示警告并重算。

每天首次运行及用户修改任务/作息时重排；离线跨过多天只整理一次当前状态，不补做多天关系加分。当天错过某个学习时段后，可以点击重新检查安排或汇报进度。当前没有持续定位、自动识别实际学习状态或外部日历同步。

## 记忆与人格

人格、关系阶段、多个关系维度、情绪和未解决冲突存入 SQLite；刷新、重启和切换模型不会创建新角色。情绪按照真实经过的时间衰减。

关系发展必须先由聊天产生提议，再明确确认；提议必须逐字对应你本轮表达的意愿，她不能自己发起；不靠充值、消息数量或学习完成率自动升级。初始称呼为「你」。普通任务完成只影响当下欣慰情绪，不兑换亲密度。角色剧情与现实事件在共同经历中分开标记。

当前采用结构化记忆和有限上下文：最近对话、近期共同事件和摘要进入模型；长期记忆最多 40 条，其中最新 16 条固定保留，其余名额优先给和当前消息及最近三句话有相同词语的较早记忆（`src/memory-recall.mjs`）。这是字面重合检索，不是向量语义检索：换了说法的旧事仍可能需要你主动提起；所有记忆仍可在管理页查看和导出。每日摘要是确定性事实统计，尚未开展长期行为规律的自动学习。

忘记操作保留不可逆内容指纹和操作编号用于去重，不保留被清理的对话原文或旧结果。备份文件、独立任务/课表中的同一事实和服务商侧记录不在此操作的删除范围内。

## 模型和预算

默认文字对话、思考与学习使用 DeepSeek `deepseek-v4-pro`（V4-Pro-0813）；图片/PDF 课表识别继续使用支持图像的 `deepseek-flash`。可选 OpenAI `gpt-6-astra`。Pro 按高峰价保守估算：百万输入 9 元、缓存输入 0.30 元、输出 27 元；空闲时段服务商实际价格更低。总预算仍为每月 200 元，学习上限 10 元包含在内。型号与价格已按 2026-09-14 的[官方文档](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)核对。

包括招呼与身份询问在内的日常聊天，通常先由 DeepSeek 判断意图和复杂度，再自主选择快速或深度回复。移除了本地固定社交回答、关键词情绪判定和口吻重写；展示的正文保留模型原文。界面默认“Miku 自己判断”，也可以指定本轮方式。复杂回应或外部资料收集可请 OpenAI 提供少量建议，最终始终由 DeepSeek 书写。页面显示实际思考方式及顾问是否参与。

OpenAI 顾问默认月上限 30 元、每日最多 4 次，费用包含在 200 元总预算中；查资料最多进行一次网页搜索并保留来源，搜索工具费用也计入预算。主动联系同样可先向顾问征求短建议，但没有内容可说时允许不发。顾问未启用时，DeepSeek 独立工作；支持的公开来源仍可由本地网页工具读取，超出能力时说明限制，不假装完成检索。

OpenAI 仍需你自行具备受支持的账号和接入条件，默认关闭。其可用地区见 [OpenAI 官方支持范围](https://developers.openai.com/api/docs/supported-countries)。

账本记录输入、缓存命中、输出（含推理输出）、响应时间和失败状态。调用前以输入字节上界、图片保守额度和输出上限预留预算，在途请求也计入；预算不足时不发起请求，已排定提醒继续工作。失败且没有完整用量回执时保留预留值，不假定免费。

费用是应用侧保守估算：DeepSeek 按峰时输入 ¥2/百万 token、缓存命中 ¥0.04/百万、输出 ¥8/百万计入，未扣除非峰时优惠；OpenAI 按输入 $10/百万、缓存命中 $1/百万、输出 $50/百万折算，美元汇率默认 7.5，可修改。预留还覆盖较高的缓存写入单价。依据 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 与 [OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-6-astra)。

200 元是这一个本地应用的新增调用限额，不能控制你在其他程序或服务商网站产生的费用。服务商实际账单、汇率和未来价格变动仍需核对；本地估算可能更早用满。测试连接也会产生少量费用，不需要一次充值 200 元。

## 主动提醒与恢复

默认免打扰 22:30–07:00；普通主动聊天默认每天最多 6 组，每组由模型决定文字与表情，可在「她想做的事」调整。默认不要求先回复，组间及最近用户发言后至少间隔半小时。日程提醒另有每天 8 次上限，相邻至少间隔 10 分钟；忙碌日可能合并或跳过部分提醒。

消息保存在持久队列，包含等待、发送中、已发送、失败、过期、撤销与合并状态。过期提醒不补发，多条仍有效的旧提醒会合并为当前计划摘要。失败使用同一个发送标识重试；断网边界仍需真实设备试用，不能保证跨服务绝对只送达一次。聊天回复不受免打扰限制，因为它是在回应你刚刚发来的消息。

本地「已发送」表示提醒已写入控制台记录，不是 Windows 系统通知。手机推送依赖飞书和手机系统设置。本机默认仅监听 127.0.0.1，手机通过飞书使用，不通过这个本地网页地址访问。

## 数据、备份和移机

- `data/miku.sqlite`：业务数据；运行时可能同时存在 `-wal`、`-shm` 文件。
- `data/config.json`：本地密钥和飞书配置，浏览器不会回显密钥。源码包不包含它。
- `data/server.log` / `server-error.log`：启动排错记录。
- 控制台左下角「导出我的数据」：导出可阅读的 JSON，不包含模型密钥。此版本没有 JSON 自动恢复按钮。

完整恢复方法：先停止 Miku，再把整个 `data` 文件夹复制备份；恢复时同样先停止，再用备份的 `data` 替换。本机首次验收未录入任何模拟用户课程、记忆或任务。

换电脑使用源码包时：安装 Node.js 24 和 npm，在项目目录运行 `npm install`，再双击启动入口。也可以用 `pnpm install --frozen-lockfile` 按锁文件安装。依赖分别为飞书官方 SDK、PDF.js 和本地 Canvas；无需 GPU。
