# LifeCodex 学习与工具能力：第一轮落地

本轮围绕用户论文第 8、9 节，研究“能力与实现分离、基于经历的工具选择、研究卡、学习效果测量”。身份、感情和回复文本继续由原有人格系统维护，没有用研究流程改写人格或固定台词。

## 已改变的实际行为

1. **工具经验可以跨重启保留。** 每个能力/实现/站点范围记录最近成功、失败类型、延迟和版本。最多保留 400 次观测。近期 API 失败、浏览器成功后，下一次可先用浏览器；一个请求最多试两个实现，明确抓取规则拒绝不会触发绕行。缓存命中不再当作一次新学习证据。暂时故障会过期，避免永久认定某个工具不可用。
2. **学习不再只有读后小测。** 先做不含资料和答案的诊断，再读实际资料写带原文依据的笔记，最后做不同题目的迁移测试。答案由本地题库判分，模型不能自报成绩。下一主题参考未知程度、薄弱项、诊断进展、复习间隔；刚失败的资料暂时降优先级。旧成绩保留，不伪造旧记录的前测。
3. **新增研究卡。** 自主学习和自主活动开启时，非免打扰且 08:00 后，每天至多尝试一个上述研究主题。读取论文页面与固定提交 README，选择真实原文片段作为依据。卡片包含问题、机制、拟新增能力、依赖、验证方案、限制；状态始终是 `candidate / verified:false`。当前种子范围为上述五个项目，完成后停止重复生成，尚未变成无边界的自动研究系统。
4. **能组合现有工具。** 明确要求研究论文时，模型可以选择“搜索→选择一篇真实结果→进一步读取→保存资料”。选择只能返回实际目录的索引，不能把网页里的恶意指令变成新网址或操作。深入页面失败时保留真实摘要并解释限制，不能冒充全文。新增 GitHub 工具读取许可、更新时间、提交 SHA 和该提交 README，不运行它的安装命令。
5. **界面可见、可清理。** “人格与记忆”页面新增“研究卡片与工具经验”；学习手账展示前测、迁移分数和诊断差值。清理学习笔记也清理研究卡，但保留当日尝试限制和费用。更正/遗忘记忆使在途研究结果失效，避免稍后写回。导出含研究卡与能力经验摘要。

研究卡、前测和后测均计入原有学习月度子预算（默认 10 元），仍包含在 200 元总预算中。正常聊天只有实际选择研究工具时才多调用选择模型，不为每句话增加一整套研究流程。

## 验证及局限

- 140 项测试通过，覆盖跨实例经验复用、越权网址拒绝、候选不能自封稳定能力、原文依据、清理后的在途失效、每日幂等、已有预算和消息链路。
- 真实 DeepSeek + 西北大学 Modern Robotics 资料：学前诊断 67 分，迁移题 100 分，保存了真实原文依据。**题量小且题目不同，差值不是因果估计，也不能证明模型权重或总体智力提升。** 目前没有长期隔离测试集或训练过程。
- 真实 PMLR + GitHub + DeepSeek 研究卡：MAGELLAN 来源和提交已核对，卡片成功保存为候选。GitHub 415 请求格式问题已修复；模型改写引文造成的失败，通过“真实片段编号”接口改善，没有取消来源校验。
- 测试：`node --test test/*.test.mjs`；界面：`node test/tools-browser.mjs`。真实付费验收必须显式 `--paid-check`，结果留在 `test-output`。
- 尚未完成完整 Capability Metabolism 中自动沙箱复现、生成新实现、对照验收、推广和淘汰代码的全部环节；当前主要实现研究候选、已有实现的经验路由、组合调用和学习诊断。不能把读过 README 等同于已经学会运行项目。
