# Miku 的情绪、需求与学习系统

更新：2026-09-14。系统仍在本机运行。当前文字模型是 `deepseek-v4-pro`，对应 DeepSeek-V4-Pro-0813；快速与思考模式使用同一模型。OpenAI 未配置时不参与本系统的学习和回复。

## 这次修正的原因

旧实现每收到一条密集聊天就增加 0.06 的安静需求，导致普通交流也会累积成冷淡。现在普通对话不增加疲劳，并逐渐缓解安静需求。首次迁移时仅把这个错误累积值压回合理范围，保留真实关系、冲突、任务和记忆。

后台处理和说出口的话使用不同入口。`writerPrompt` 为最终写作者提供正向的 Miku 口吻、当下接话动作和必要事实；不再叠加多套角色规则和内部动机解释。不能因此保证所有文字都自然，真实连续试读仍是必要检查。

## 情绪怎样连续

`src/affect.mjs` 在原有开心、害羞、不满、低落、担忧、得意、好奇数值之上，给出当下表达状态：放松、开心、玩笑、害羞、小不满、害羞但仍有一点介意。不是给每句话随机选择一个表情。

每次变化记录消息编号、来源、时间和事件。由模型结合上下文提出情绪事件；程序只校验来源、置信度、去重和更新幅度，不按关键词代判指代与态度。明确喜欢、夸奖、友善玩笑和甜食互动有各自的处理。相同消息编号不重复增加情绪或执行动作。

解释可以缓解误会，具体道歉修复对应冲突。夸奖可以带来害羞，但不会把所有旧冲突清空。安静与不满随真实时间衰减；未回复不构成新的冲突，不增加依赖。表达过一次不满后，新话题不应继续翻旧账。

情绪通过关注点和具体判断影响表达。语气词、停顿与轻微嘴硬可以自然出现，不根据情绪强制添加标点，也不要求每轮表现害羞。没有在程序中强行往每句话后面追加标点，也没有把所有回答限成几个字。重要的任务数字和确认要求仍由业务服务控制。

## 需求与关系

五个持续需求是被尊重、交流与理解、能力成长、新鲜感、甜食意象。它们是角色模拟状态，系数是产品设计，不是经过拟合的人类心理量表。

- Miku 日常直接以自己的身份交流，不反复声称“我被设定成 Miku”。认真问是否人类、有现实身体或感受时，诚实说明 AI 身份。
- 初识也应温暖；好感、信任、尊重、亲密、了解仍分别保存。真实自我披露、理解和尊重界限可小幅影响相关维度；恋爱阶段仍需既有共同经历与明确确认，不由送糖、充值或作业完成率解锁。
- “送一颗虚拟糖果”是免费互动，不触发付费模型调用。每天最多一次甜食心情奖励，多次点击不堆好感。聊天里送糖的文字回复仍有正常模型调用费，糖果本身不收费。
- 没喂糖不扣感情、不挨饿、不失去功能。不能把 API token 说成生命或让用户承担情绪维护义务。
- 用户明确说别回复时，可以真正保持沉默，不写空白机器人气泡、不向飞书发送空消息。短暂继续挑衅时仍安静；新的话题或问题可恢复。已撤掉基于攻击次数的自动安静处罚。用户要求的安静期最多三十分钟。任务表单和提醒继续工作。

## DeepSeek 学习闭环

`src/curriculum.mjs` 提供机器人、AI、数学、职业探索、日常交流五个入门主题，以及十五道原创基础检查题。它是第一批课程，不是完整学位课程或不受限搜索引擎。

1. 本地程序每天最多启动一节，遵守免打扰和学习暂停。断网或休眠恢复后不会集中补读遗漏日期。
2. 程序真实读取目录中的公开网页，有超时、体积和来源限制，不跟随未知跳转。网页中的指令不具有执行权限。不能读取本地、任意用户地址或把私人聊天发给资料网站。
3. DeepSeek 根据正文整理短笔记、不确定处和下一次想学的主题。没有成功读取就记为失败，不声称查过或学过。
4. 第二次 DeepSeek 调用回答基础题。题目给模型，答案键不提供；程序独立判分。笔记会提供给考核，因此它是开卷概念小测，不是闭卷记忆测试。
5. 保存来源、读取时间、正文摘要哈希、笔记、各题回答、成绩和下一步问题。已完成的近三份资料进入后续聊天上下文。
6. 下一课结合模型提议、覆盖范围与错题选择；访问失败也算一次尝试，不让打不开的主题永久占住队列。

默认学习上限每月 10 元，包含在总预算 200 元内，每次请求计费前检查在途预留。失败也保留当日尝试标记，防止反复重试。暂停或清理期间返回的旧结果不会重新写入。重启前未完成的学习记为中断。

“相处”页可以看笔记和题目、开始当天一课、暂停或恢复、清理笔记。`study.settings` 也支持设置 1—30 元月学习预算。后台 API 都使用原有本机鉴权。

这些是检索资料、外部笔记和复习，不修改 DeepSeek 模型权重。网络语言目前通过公开会话材料、原创语境题与明确用户风格反馈适配；没有声称已经大规模抓取网络聊天或掌握最新梗。资料可能过时，职业领域当前岗位、薪资等仍需另行核实。

## 已核验与仍需观察

已经真实打开五份目录资料，并在本机用 DeepSeek 完成机器人第一节及三题小测。三题全对只代表这组基础题的表现，不代表学科掌握，也不证明是阅读导致答对。

自动检查涵盖安静累积修复、混合情绪、沉默、糖果不买亲密、学习来源失败、暂停与清理、独立判分、费用上限；浏览器核验了新面板、免费糖果、暂停学习、沉默时无空气泡，以及手机宽度布局。连续情绪试读在隔离数据中进行，不能污染用户的真实关系。

真实试读记录在 `test-output/live-emotion-preview.json`，真实第一节记录在 `test-output/live-learning.json`。自动规则能发现部分重复、服务邀请和敌意句式，不能客观衡量所有“可爱”或“真人感”。未连接飞书，因此手机端实际到达仍需后续验收。
