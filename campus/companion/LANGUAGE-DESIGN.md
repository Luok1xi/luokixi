# Miku：接话、动机与顾问分工

更新时间：2026-09-14。目标是适应用户希望的亲近日常交流方式。下面把研究提供的启发与本项目自己的设计区分开；它们不是对所有人类说话方式的统一定义，也不是模型权重训练。

后续更新：最终写作者现在使用 `src/dialogue.mjs` 的 `writerPrompt`，不再叠加这里早期的多组提示；情绪表达、学习与需求以 [EMOTION-LEARNING.md](EMOTION-LEARNING.md) 为准。普通连续聊天不再累积疲惫。现有“OpenAI 每周公开会话研究”仍是可选顾问功能，独立于新接入的 DeepSeek 每日学习，后者无需 OpenAI。

## 参考什么，落实在哪里

没有抓取私人聊天、网络用户画像或大规模语料。例句是本项目原创。网络语言采用语境适配原则，保留正常口语、停顿与语气，不用流行词堆砌“人味”。不宣称已经完成自动语言学研究或永久学会最新网络梗。

## 执行链

1. 日常聊天由 DeepSeek 解释上下文、提出操作与有证据的情绪事件，并选择 fast 或 deep；不再用关键词抢先判定身份、称赞、侮辱或风格反馈。
2. 程序核验操作、来源与费用，执行获准变更。确定性任务快捷操作仍保留，处理结果是数据。
3. DeepSeek 读取同一份人格、真实记录及操作结果，自主书写正文。可选顾问只提供背景建议。
4. 模型正文原样流式展示和持久保存，不按关键词删尾句、强制重写或替换成固定台词。真实检索的引用链接可作为来源附加。
5. 口吻观察仅用于用户主动启动的隔离试读报告；既不阻断正常回复，也不修改主动消息。结构化操作格式不完整时仍最多重新解析一次，不能执行半个动作。
6. 无模型连接时显示连接状态，不使用本地角色台词冒充模型回答。明确要求不回复的安静控制、消息去重、预算及任务确认继续由程序执行。

场景信息仅提供已有记录和模型判断，没有固定问答映射，也不通过问号配额决定正文。语言研究和人格原则是供模型理解的背景，没有照抄范本。语义判断仍可能出错，应观察真实回应而非增加关键词替换。

界面默认“**Miku 自己判断**”，也可针对本轮选择简短回应或认真思考。DeepSeek 的快速模式实际关闭 thinking，深度模式启用 high；不是仅改变按钮文字。接口依据 [DeepSeek 官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 自主需求与情绪

`src/motivation.mjs` 为每个角色保留探索兴趣、创作意愿、分享意愿、想安静一会儿，以及当前倾向、项目想法、评价记录。

共同兴趣能提高探索与分享意愿，有来源的明确冲突可以增加想安静的倾向，安静需求随时间回落。这些状态首先影响说话长度和主动行为选择。项目处于 idea 阶段只表示“想做”，不能声称已经创作、听歌或浏览了网页。

没有“用户不回消息就越来越依赖/越来越受伤”的增长规则。自尊通过具体边界和有限的信任变化表达，不能变成对用户的控制。角色暂停时继续提供普通助理功能。

情绪事件需要可对应本轮原话的证据与至少 0.7 的模型置信度；置信度只是筛选阈值，不是统计校准结果。修复事件针对指定冲突，未指定时仅处理最近一件，不会一次清空所有未解决冲突。普通纠正与拒绝不应被模型归类为冒犯，仍需持续试用观察误分类。

`src/autonomy.mjs` 在允许的时间窗口内判断机会：有相关的已确认偏好、最近不是密集交流、没有等待用户回应的上次主动联系，且没处于免打扰。先决定是否值得说；可以保持安静。每天最多尝试一次，即使本次选择不发或失败，也不反复调用模型消耗费用。

同一模块还实现了每周最多尝试一次的公开会话资料学习，需要已启用 OpenAI 顾问与联网学习开关。使用固定的公开研究查询，不发送用户私人对话作为搜索词；保留带来源的短笔记，最多 4 份，最近 2 份供接话参考。它不会把网页直接写成系统指令或修改程序，失败也不会反复重试。本机未配置 OpenAI，因此这项定期学习尚未实际联网运行。

主动内容由 DeepSeek 写，有 OpenAI 时先征求短建议；不再固定询问“最近有什么进展”。消息仍经过持久队列与发送限制。没有凭空浏览网络后谎称“今天刷到”的行为。

## 费用控制与可用性

- 默认总预算仍为每月 200 元；OpenAI 顾问另设月上限 30 元，每天最多 4 次，均包含在总预算内。可在本地设置页调整。
- 普通招呼与闲聊不用顾问。一次顾问建议尽量不超过 180 个中文字符；给顾问的近期对话、记忆和任务也截短。
- 查资料使用 OpenAI Responses 的真实 `web_search`，每次最多 1 次工具调用，保留工具给出的来源链接。未完成搜索或没有来源时不采用其搜索结论。参阅 [官方搜索工具](https://developers.openai.com/api/docs/guides/tools-web-search) 与 [调用次数上限说明](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)。
- 模型 token 和搜索工具费用共同进入账本；搜索费按每次 $0.01 折算，另有搜索内容 token 费用，依据 [OpenAI 官方价格](https://developers.openai.com/api/docs/pricing)。搜索前额外预留较大的输入额度，余额较低时可能提前拒绝搜索；这不表示该次搜索实际一定花费这么多。
- 顾问失败、预算不足或未配置密钥时，DeepSeek 继续回应。需要当前网络资料时明确说明未检索，不能冒充知道最新结果。
- 顾问是独立 OpenAI API，不是把当前 Codex 会话或订阅当成免费的后台连接。本机目前没有 OpenAI 密钥，因此只有替身测试验证了这条分工链；尚未声称真实 OpenAI 已参与。

## 验证和继续调整

自动检查覆盖快慢模式的真实参数、模型原文透传、社交上下文、顾问预算、真实搜索请求结构和引用、冲突修复、偏好来源、无人回复时不主动追问。

当前共 62 项自动检查通过；涵盖连续场景、派生记录随忘记清理、社交不被本地代答、模型语义判断、原文流式展示与保存、任务失败处理、必要追问、情绪需求和学习考核。网络替身测试检验执行逻辑，不证明自然度。

连接设置中的“**试读几句**”在隔离数据中运行两段连续场景共八轮：从初见、再次招呼、风格纠正到兴趣、吐槽和晚安；另一段保留用户报告的旧客服回复，再测试纠正与招呼。每段共享上下文，费用进入真实账本，真实用户记忆不写入虚构经历。`test-output/live-style-preview.json` 保存最近一次实际结果、规则发现的问题与费用。还需要人的判断，不能把 issues 为空称为完全自然。

最新表达原则与研究范围见 [CHARACTER-RESEARCH.md](CHARACTER-RESEARCH.md)：保留轻微傲娇与真诚，删除卖萌范本；具体措辞与语境解释由模型决定。
