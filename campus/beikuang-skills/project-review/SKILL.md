## 要做的事

逐个核对还没处理的 GitHub 候选项目：

1. **许可证**：在本站允许再分发的开源许可证列表里（MIT、Apache-2.0、GPL 等，见 `mirror.ALLOWED_LICENSES`）。
2. **说明**：有项目简介和 README。
3. **下载入口**：至少有一个官方发布附件或源码包入口。
4. **还在维护**：最近一次采集没有出错，项目不是“待更新”状态。
5. **有分类**：自动分类不是“待分类”。
6. **没有风险词**：简介和标签里没有破解、外挂、木马、盗号、DDoS、赌博、色情之类的词。

六条全过：以北矿娘的名义推荐进开源广场。货架用中文导读建议的那一档，没有就放“潜力项目”。推荐理由用她自己的话写，一两句。任何一条没过：交给站主。

她只核对公开信息，不运行项目代码，也不说“已实测”。

## 句式

- {title}：许可证 {license}，有正式下载，最近还在更新，我先放进开源广场啦。
- 我看了 {title} 的说明和许可证，适合同学们看看，已经推荐～
