# 美术规范：带一点矿大的味道

> 负责：Codex 创作，Claude 审稿（逐张给出“通过 / 修改 / 退回”和具体理由）。
> 原则：**带一点就好。** 矿大元素是点睛，不是主角；整体仍然是苹果式的克制。

## 一、不能碰的（任何一条踩到都直接退回）

1. **不用官方标识。** 不用校徽，也不要做出“同心圆环 + 地球 + 火炬 + 双手”这类容易被认成校徽的组合；不模仿邓体校名、校旗或领导人题字。网站是非官方的，不能让人误以为是学校官方出品。
2. **不搬官方照片。** 学校官网的校园照片有版权，不能直接用，也不能拿来“描一张”。要用真实校园照片，只能用同学自己拍、并且授权给本站的。
3. **不画真人。** 不出现可辨认的人脸，不出现老师、领导或同学的形象。
4. **画面里不出现任何文字、数字和品牌**（包括“1909”和“CUMTB”这类字样）。文字一律由页面排版负责。
5. **不冒充实拍。** 所有 AI 生成的图都标注为“概念插画”，元数据里写明工具、提示词和日期。
6. **不出现科学错误。** 机械图里的齿轮要啮合，轴要同心，螺丝要对准孔；地层图的层序要合理，不能把煤层画成竖着的彩虹。
7. **不用学校的照片、建筑或标识去做“推荐”或“背书”的暗示。**

## 二、矿大元素清单（每张图最多用一个）

| 元素 | 用法 | 为什么选它 |
|---|---|---|
| **矿灯的光** | 一束温暖的光切开黑暗，照亮前方的东西 | 采矿的人靠它在地下看路；对学生来说，它就是“把路照亮”。不直接用火炬，避开校徽 |
| **地层** | 一层层水平的岩层剖面，边缘有细微的发光 | 地质和采矿的专业语言；和首页“一层层试卷”的堆叠在概念上呼应 |
| **矿物晶体** | 黄铁矿的立方体、石英的六棱柱、煤的断面 | 适合做徽章、成就和分类图标 |
| **井架** | 只用线稿剪影，作为小图标或分隔装饰 | 矿业最有辨识度的轮廓 |
| **学院路的老楼** | 只用 1950 年代对称主楼的抽象剪影，不复刻具体某栋楼 | 学院路“八大学院”的共同记忆；等有同学授权的照片后再考虑具体化 |

## 三、色彩

- 网站原有的招牌渐变（蓝 → 紫 → 红 → 橙）保持不变。
- 新增一个**矿大红**作为学校时刻的点缀色。浅色模式 `#b4182d`，深色模式 `#ff5a6e`，变量名 `--cumtb`。
  这是**我们对“矿大红”的诠释，不是学校公布的标准色值**，页面和文档里都不能把它写成“官方色”。
- 一张图里矿大红的面积**不超过 10%**：一块零件、一道光、一层岩层就够了。
- 整体不超过 3 种主色，加上招牌渐变里的点缀。

## 四、技术规格

- 格式：照片质感的用 WebP，图标和纹理用 SVG（只用 `currentColor`，这样能自动适配深浅色）。
- 大小：主视觉（2400 宽）不超过 300 KB，其他不超过 200 KB。SVG 不超过 20 KB。
- 构图：主体放在中间 60% 的安全区里，保证 16:9、4:3、1:1 三种裁切都不会切掉主体。
- 光线：一盏柔和的主光，和现有的 `community-engineering.webp` 一致。背景是纯黑或纯白的影棚。
- 需要放在深色区块的图，交一张深底的；同时要用在浅色区块的，深浅各交一张。
- 每张图配一个 `.json` 元数据：`{asset, created, tool, prompt, usage:"概念插画", review}`。
