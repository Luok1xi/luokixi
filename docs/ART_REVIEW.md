**修改方向**

1. **画风往迪士尼导览图靠**：明亮、饱和但柔和；屋顶按用途分色，和页面图例同一套色相（`map.css` 的 `--b-*`：教学楼暖橙、图书馆淡紫、食堂奶黄、宿舍天蓝、体育珊瑚红、实验楼薄荷绿、会堂粉色），这样标签和图例能对上；树冠更圆润成簇，园路暖米色，校园外一圈柔和绿篱。保持无文字、无角色、无标志。
2. **楼高按层数**：有 OSM 层数的按比例画；没有的按卫星阴影估计并登记。
3. **改正球场和地物**：按 OSM 的 `sport` 标签画篮球、排球、网球场线；沙河西侧顶棚、南门广场按卫星画。
4. **约定不变**：屋顶对齐黄线，立面向画面下方（`CAMPUS_MAP_ART.md` 第 3 节已按这个约定更正）。待核对的观察屋顶可以画，但页面不会把它们做成可点击的楼。

改完以后按 Codex 提出的顺序继续：逐栋校准 → z19 偏差量测 → 正式画布 WebP → Opus 审批，把 `manifest.json` 里的条目改成 `approved`。
