### 工具选择、安装与试验

两位原版角色共用既有 maintenance 工具链，保留各自人格和记忆。`tools` 读取适配目录，`tool_install` 下载固定版本的官方 Python wheel、校验 SHA-256、试运行，成功才启用；`tool_run` 实际读取文本或资料 PDF。失败、耗时、版本、来源、试验结果存入现有记录。工作室的“可安装工具与真实试验记录”可以查看。

已真实安装并试用：Markdown 结构阅读器（markdown-it-py 4.0.0、mdurl 0.1.2），PDF 文本检查器（pypdf 6.19.0）。后者对扫描件明确报告需要 OCR，不能把扫描 PDF 当成已识别的题目。

`tools.adapterSource` 指向 `campus/hub/robot_tool_adapters.py`。原版 AI 可以按既有 code_read → code_candidate → code_test → code_apply 流程扩展依赖和试验程序。改动在后续调用时重载，版本变化须重新安装试运行。下载边界、权限、预算、密钥和记忆不在适配源码内。当前支持通用 Python wheel；不是所有系统软件的通用安装器。

包安装在独立目录，试验使用独立 Python 进程且不传模型密钥。**这属于环境与数据隔离，不是操作系统沙箱。** 现有 GitHub SKILL 文档的评估、固定提交和许可检查保留，不把文档下载说成工具已会使用。

真实双运行时 `/tools` 均读到了新目录。最后一项“由模型自主选工具并运行”的实测被当前每日 ¥10 限额拦截，未执行、未提高额度；不能把操作员的工具验收说成北矿娘自行完成。

### 配图与空间感

对没有原始图片的已发布文章，生成与本文标题、来源、日期对应的独立 SVG 主题封面，注明“非事件实拍”。50 篇已更新，11 篇原始媒体保留。独立 URL 带内容版本，支持站内查看与下载；包含 XML 转义和内容限制。日期不再在大标题里拦腰断行。

原照片、立绘、地图和光碟设计保留。单图增加轻微悬停缩放；滑轨保留纵深、反向视差、拖动与吸附。尺寸集中测量，惯性按实际帧间隔衰减，离屏照片减少更新，尊重减少动态效果。

这些主题封面保证不冒充新闻现场；没有声称已经自动核验所有历史上传图片的语义或修复所有外部坏链。

### 中文与站内下载

项目优先展示已有中文导读；原文折叠为对照。前沿新闻保存中文摘要及原始摘要与来源，不冒充全文翻译。站内阅读与导出保留中文和原文的分别入口。修复手机项目导读长地址及章节目录撑宽页面。

镜像文件新增“加速下载”：最多 3 个连接、1 MiB 分段、浏览器本地续传、强 ETag 版本绑定、最终 SHA-256 校验；失败不保存损坏的文件。普通下载入口保留。浏览器缓存清理 7 天前的分段，启动时限制历史缓存；超过 128 MiB 的文件转普通下载，避免过大的合并内存。**不承诺固定倍数提速，速度仍受源站与网络制约。**

已核对的中文导读可生成四段图文讲解，站内播放并导出 WebM，带来源。标注“自动图文讲解，非软件实录”；不是把任意 GitHub 软件运行成功的录屏。

验收时真实覆盖：36 个项目，23 份已核对中文导读；16 个项目有本站下载，共 33 份本地文件。仍有来源读取失败、待翻译、许可无法确认、下载超时及预算限制。未伪造缺失包，未以外链冒充本站镜像。机器人工作台逐项目显示未完成原因。

### 人格日志

日志仍由原版 Chat.compose 使用原人格、情绪和已学习的表达偏好生成；消息链中的表情随日志保存。主页手记和详情显示角色头像及模型选择的心情。执行数据、未解决事项单独列出，不再强制拼一段机械结语。

实测发现北矿娘原来会把旧私聊的邮箱故障和工作数字写进当前公开报告。现已把公开日志的事实输入限定为本轮公开执行记录；保留同一份人格、情绪与语言偏好，私聊及工作室仍保留原记忆连续性。没有删记忆。修复后两位模型均生成了新日志预览，旧邮箱故障没有再次混入；预览未替换已有公开日志。下一次正常日志生成使用新逻辑。
