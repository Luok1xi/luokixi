# v0.2 · 六板块改版验收

2026-10-06。用户明确授权 Codex 接手这一版前端改版，完成后只公开 Luokixi GitHub 仓库，不部署在线网站。历史文档中的 Opus 独占前端、仅规划及禁止上传约定，在本轮相应范围内已被新授权取代。

## Before | After | Why

| Before | After | Why |
|---|---|---|
| 首页平移轮播，重要信息入口分散 | Collins 风格透视扇形切换，支持拖动、键盘、边界阻尼与减少动态效果 | 突出当前一条新闻，保持上下文且不抢夺手机纵向滚动 |
| 动态页面被预渲染，后台重复加载地图和接口 | 仅适度预取静态入口；页面切换过渡与按需动画 | 降低未进入页面的后台工作量；未据此声称达到固定帧率 |
| 地图前有大段介绍，设施入口隐蔽 | 入页即地图，设施快捷入口、独立图标、详情优先预约链接 | 找地点后直接行动，保留真实空间与未接入状态 |
| 真题按考试拆成多个页面 | 全校资料检索、上传审核、资料袋、原文件 ZIP 与来源清单 | 可以组合不同课程的资料，避免逐个下载 |
| 校园论坛和评价缺少集中入口 | 校区论坛与竖排口碑列表互通 | 区分讨论与评价，同时保留原评论和原有匿名权限 |
| 项目列表缺少连续发现体验 | 单项目竖滑流、原仓库/视频/详情入口、可关闭评论弹幕 | 先看用途再展开；无真实视频时不放假播放器 |
| AI 协作只有接口 | 站主房间、成员状态、逐轮记录、候选查看与确认 | 让现有真实后端可操作，同时清楚显示实际提供方 |

## 已执行验证

- Django Hub：68 项测试通过，包括匿名评价、贡献撤回、权限、工作室预算与候选审核；新增公开目录附件只能来自已发布版本、草稿或撤回附件不能读取。
- 资料袋：4 项 Node 测试通过，覆盖文件字节与 UTF-8 文件名、来源清单、URL 限制、失败/超限/取消行为。
- 内容校验和 Vite 正式构建通过；99 个模块。
- Edge 浏览器：1440×1000 和 390×844 视口的首页、地图、资料、校圈、口碑、开源流、工作室均检查，无横向溢出与页面脚本错误。
- 原本机资料：真实选择两份 PDF，成功下载 ZIP、解压及逐字节验证。搜索“线代”返回真实线性代数资料。
- 独立测试账号与数据库：页面上传原创文本 → 审核前匿名不可见 → 维护者批准 → 手机搜索 → ZIP 原字节下载。
- 页面发帖 → 审核 → 另一账号点赞和回复 → 学院路/沙河筛选正确；未在真实社区制造演示帖子。
- 站主页面创建工作房间成功；普通账号访问工作室被拒绝。验收未触发付费调用。
- 手机图书馆图标进入详情并提供已核对官方链接；轮播实际指针拖动有效，减少动态效果模式停用自动播放与透视运动。

## 公开源码检查

在独立、无共享依赖的目录执行 `npm ci --ignore-scripts`、内容校验、资料打包测试及正式构建成功；待公开副本自身的 68 项 Hub 回归也通过。静态副本在手机视口正确显示缺少私人试卷的空状态，不伪造下载项。手机图书馆详情中官方预约按钮无需向下滚动即可看到。

扫描待公开源码与原有 Git 历史的常见凭据模式，未发现待处理命中；此检查不等于全面安全审计。`.data`、账号配置、私有文件与模型密钥排除。Pages 工作流仅保留手动入口，推送不会部署网站。

## 保留的限制

无公网部署、实体手机、校园实地或高并发测试。SMTP、OAuth、真实空位、学校预约接口和真正 Anthropic 接入待配置。DeepSeek 适配器通过隔离测试，本机未填密钥，未做其付费实调。AI 工作室候选自动检查范围有限，确认候选不等于功能验收或发布。

全校资料分类与投稿路径已具备，实际内容由维护者和同学持续补充。现有本机私人资料不进入公共仓库。待审校园插画仅作设计候选，不能代替地图地理数据。

学校新闻来源：[国庆升旗仪式报道](https://news8.cumtb.edu.cn/info/1003/40686.htm)（2026-10-01 发布，2026-10-06 核对）。预约入口：[学校图书馆](https://lib.cumtb.edu.cn/)、[体育场馆官方预约指引](https://tiyu.cumtb.edu.cn/xwzx/cgyy.htm)。轮播参照 [Dimi 原示例](https://www.dimi.me/lab/collins-carousel)，使用自写实现。
