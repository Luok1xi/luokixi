# 设计与动效规范

目标：像 apple.com 一样克制。大字、留白、少颜色，动效服务于阅读。

## 设计变量

所有颜色、字号、圆角、缓动曲线都定义在 `src/styles/tokens.css`，组件里只引用变量，不写死数值。深色模式在同一个文件里重新赋值，同时支持跟随系统和手动切换。

| 用途 | 变量 |
|---|---|
| 背景 / 交替背景 / 卡片 | `--bg` `--bg-alt` `--card-bg` |
| 文字 主 / 次 / 弱 | `--fg` `--fg-2` `--fg-3` |
| 强调（按钮、链接） | `--accent` `--link` |
| 招牌渐变（蓝→紫→红→橙） | `--glow`，每页只用 1–2 处 |
| 大标题 | `--fs-hero` `--fs-h1` `--fs-h2` |

## 组件（`src/styles/components.css`）

`.btn-primary` `.btn-outline`（苹果官网现在的“实心 + 描边”按钮组合）`.btn-secondary` `.btn-link` · `.segmented` · `.tag` `.cat-tag` · `.card` `.card-hover` · `.glow-ring`（流光描边）+ `.glow-halo`（光晕）· `.notice` · `.localnav` + `.jumpbar` · `.gallery`（横向画廊）· `.player`（听力播放器）

v2 新增：`.glass`（Liquid Glass 风格的毛玻璃）· `.dlg`（原生 `<dialog>`，进出场动画用 `@starting-style`）· `.avatar`（GitHub 头像，加载失败自动显示首字）· `.cover`（生成式封面，见 `src/js/cover.js`）· `.proj-card` · `.heat`（平面热力图）· `.promo-grid` + `.promo`（苹果首页的双联宣传格）· `.spot`（⌘K 全站搜索）

## 排版与可读性

- 正文行高 1.6，中英文之间自动留空（`text-autospace`），行首全角标点挤压（`text-spacing-trim`）。
- 允许合成粗体（`font-synthesis: weight`）。部分中文字体只装了常规体，不开这个选项，标题就没有粗细层级。
- 12–14px 的小字用 `--fg-2`，不要用 `--fg-3`。浅色模式下 `--fg-3` 已加深到 #6f6f74，以满足 4.5:1 的对比度。

新页面优先复用这些组件。需要新增组件时，加到 `components.css`，并在本文件里登记。

## 动效原则

1. **只动 `transform` 和 `opacity`。** 不对 `width`、`top`、`filter`、`background-position`、`box-shadow` 做逐帧动画。
2. **入场统一用 `data-reveal`**：上移 30px，淡入 1 秒，曲线 `--ease-apple`；兄弟元素之间自动错开 80ms。`data-reveal="scale"` 改成从 0.94 放大到 1。
3. **循环动画要挂 `data-live`**：只有进入视口时才加 `.is-live` 并播放，离开视口立即暂停。
4. **滚动联动交给 GSAP ScrollTrigger**，统一写在 `gsap.matchMedia()` 里，并设置 `prefers-reduced-motion: no-preference` 条件。系统开启“减少动态效果”时，直接显示最终画面。
5. **不劫持滚动。** 横向内容用原生滚动加吸附（`.gallery`），不做钉住后横移。
6. 渐变字保持静止，不做流动动画。

# 第三版设计方向：排版学虎扑，界面学 App Store（2026-10-06 Owner 确认）

**为什么这样组合**：虎扑擅长把一个社区里大量的帖子、榜单、评分组织得又密又好找；App Store 擅长把评分、评论和精选内容做得清楚、好看。Luokixi 的六个板块里大部分是“社区内容 + 评分 + 精选”，正好是这两者的交集。只学版式规律和交互习惯，不用他们的商标、图标、配色和名字。

## 一、全站骨架

- **桌面端顶栏**：左边是标志，中间是六个板块（首页、校园、资料、校圈、开源广场、个人中心），右边依次是搜索、“＋发布”、消息铃铛（有未读红点）、头像或“登录”。
- **手机端底部标签栏**（App Store 和虎扑都是这样）：首页、校园、资料、校圈、开源 五项；个人中心放在顶部右侧的头像里。“＋发布”是右下角的悬浮按钮。
- **每个板块顶部**：先是 App Store 式的大标题（34px 粗体，上方一行小字写日期或板块说明），下面是一排分段标签（虎扑式的“推荐 / 关注 / 热榜”）。

## 二、组件清单（实现时补进 components.css）

| 组件 | 学谁 | 用在哪里 |
|---|---|---|
| **精选大卡**（Today 卡）：整张大图 + 小标题 + 大标题 + 一句导语，点开展开成文章 | App Store “Today” | 首页编辑精选、专题 |
| **横向货架**：一行横滑的卡片，标题右边有“查看全部” | App Store 货架 | 首页各分区、开源推荐、相关资料 |
| **列表行**：左边圆角方形图标，中间标题和副标题，右边一个灰底蓝字的胶囊按钮（“查看”“收藏”“下载”） | App Store 应用列表 | 资料、项目、课程 |
| **评分块**：一个大号平均分（“4.6，满分 5 分”）+ 五行星级分布条 + “共 N 人评分” | App Store 评分与评论 | 课程和教师口碑；**评分人数不足 5 人时只显示“评分人数不足”，不显示平均分** |
| **评论卡**：标题、星级、学期背景、日期、正文三行截断，可展开 | App Store 评论 | 口碑原话 |
| **热榜**：1–10 名编号列表，带热度和变化箭头，说明统计时间窗口 | 虎扑热榜 | 首页热点、校圈热帖 |
| **帖子行**：标题 + 一行摘要 + 板块标签 + 回复数和“亮了”数 | 虎扑帖子列表 | 校圈 |
| **亮回复**：帖子详情顶部先放获赞最多的几条回复，再按时间排列 | 虎扑“亮了” | 校圈帖子、口碑评论 |
| **评分墙**：一格一个对象（课程或教师），显示分数、评分人数和一句最热原话 | 虎扑评分 | 选课口碑首页 |
| **板块宫格**：话题吧图标网格，显示关注状态和今日新帖数 | 虎扑专区 | 校圈首页 |

## 三、视觉规则

- 字号层级照 App Store：页面大标题 34px，分区标题 22px，列表标题 17px 粗体，副标题 15px 灰色。
- 圆角：大卡 22px，列表图标 13px（约为边长的 22%），胶囊按钮全圆角。
- 颜色：主色仍是现在的蓝 `--accent`；矿大红 `--cumtb` 只用在矿大特有的时刻（例如“本校”标签）；招牌渐变只留给首页精选和少数高光时刻。
- 信息密度：列表和帖子行学虎扑的紧凑（行高 1.45，行距 12px）；精选和详情学 App Store 的留白。**一个页面里不要两种密度混在同一块区域。**
- 动画：卡片点开时从原位置放大展开（App Store Today 的转场，用 View Transitions，不支持时直接切换），其他沿用第一节的动效原则。
- 图片：一律由 Codex 按 `docs/ART_DIRECTION.md` 提供；没有图时用纯色或渐变底加图标，**不留空白，也不用来路不明的网图**。
