# 开发者参与、站内阅读与七海原版语音接线

2026-10-09；仅本机 Luokixi，保留原资料、消息与角色记忆，无推送或公网部署。

## 开发者参与

服务器统一使用 `can_participate`：已登录、启用中的超级管理员可以免邮箱验证发帖、回复、上传及参与现有需要验证的功能。普通账号与普通管理员仍按原规则；昵称或客户端提交字段不能赋予开发者权限。`emailVerified` 不伪造为 true，新能力字段 `canParticipate` 提供给前端。

资料、校圈、项目、地图、收藏、教师页同步取消对真实开发者的邮箱拦截。个人中心说明豁免原因。模型额度、工作室本机权限和私有附件访问规则保持原有约束。

## 站内阅读与下载

- `viewer.html` 提供统一入口；原有本地资料、附件、镜像、题目导出和配图链接转入站内阅读。明确的下载按钮仍下载原件。
- PDF 由按需加载的 Mozilla PDF.js 在站内绘制，含翻页、缩放、旋转和本页文字提取；不依赖桌面浏览器 PDF 插件。一次绘制一页，限制像素数量，取消过期渲染。
- 听力与视频使用站内播放器；图片和文本可直接查看。镜像 ZIP 可浏览目录、读取 README/代码，不解压或执行内容。目录/文本有大小限制。
- 已公开帖子、新闻、公告和项目可以导出 Markdown，附上传者、时间、当前可见版本及公开讨论。不会把待审回复/草稿混入公开导出。
- 抓取网页只有提取文本时，明确标为提取文本；未存入原件的外链只导出收录说明，不假装原件已镜像。
- 照片使用现有已去除 EXIF 等隐私元数据的展示副本；私有附件继续按原权限检查。没有开放任意网址代理。
- 不支持在浏览器直接预览的二进制格式保留站内下载。加密 PDF 需要下载后解锁；没有绕过密码。

真实库只读核验：219 个条目，177 份 PDF 与 41 份 MP3 已上架，另有 1 份原本待审核的网页提取文本。218 份本地原件全部存在。

## 新世界语音对照

原版来源固定到 `RachelForster/Shinsekai` 的 `b39c8cef73fd5283c993675719e21ea808cfa5bf`：

- `ai/tts/tts_adapter.py`：GPT-SoVITS `/tts`，默认 `cut5`、batch 1、角色原速，其余采样/片段间隔留给引擎。
- `application/chat/dialog_media/tts_generation.py`：默认不额外拆分台词；预录音、失败后备用录音与合成参考录音分开，只有有台词的 reference 才能作为参考。
- `ai/llm/text_processor.py`：朗读前移除括号和星号动作描写。
- `application/runtime/audio_playback_controller.py`：单个有效播放，不叠加另一条音轨。

原版没有专门检测/去除句中吸气的 DSP 算法。本轮对齐其请求与播放行为，没有伪造一个“原版去吸气开关”。网站继续使用七海原模型与 3.97 秒原参考录音；未用缺少台词的短表情录音替换，也未添加随机喘息音轨。缓存包含生效参数；两角色的模型切换仍串行。

普通台词上限内整条合成，去掉旧的 120 字硬切；超长台词按句末/分句标点续接，下一段提前准备，避免额外等待。动作旁白只在语音边界清理，显示台词、人格与记忆不变。

试听样本及请求信息在 `campus/.data/voice-verification-20261009/shinsekai.{wav,json}`。首次实际合成耗时 4198 ms，WAV 11.66 秒、32 kHz 单声道。时间和格式不等于吸气问题已经解决；当前工具无法完成主观听感验收。该角色自身训练音色/参考录音里的气声仍可能存在。

本地原版资料与 LICENSE 放在被忽略的 `.data/shinsekai-voice-audit/`，未将上游整个项目复制入待公开源码。参考语音身份与模型不变，旧参数配置有备份。

- `scripts/verify-site-reader-live.mjs` 使用真实本机开发者会话验收，不创建公开测试帖；报告与桌面/手机截图位于 `.data/reader-verification-20261009/`。
- `scripts/verify-character-voice-live.mjs` 仅调用本机 GPT-SoVITS，不调用付费聊天模型。
- 本机健康版本：社区 27，资料服务 3，两个原版 companion 桥接 22。

最终浏览器实测包含 PDF 有效页面像素、翻页、旋转、手机适配、PDF 下载文件头、听力有效时长、新闻导出、镜像包内 README、配图、开发者上传/回复/账户提示；全部通过，无浏览器脚本错误。

快速页面切换曾复现短暂连接拒绝，资料进程并未退出。原本 HTTP 接入队列沿用默认 5；40 个同时到来的健康请求实测仅 22 个成功。队列扩大到 128，并忽略客户端切页取消导致的断连写入后，同样 40 个请求全部成功（25 ms）。结果保存在 `.data/reader-verification-20261009/queue-burst.json`；这是本机短时突发检查，不代表公网负载容量承诺。

构建产生现有大模块体积提示；PDF 模块仅在打开 PDF 时加载，字体/解码资源随站点本地提供。
