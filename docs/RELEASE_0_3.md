# v0.3 · 纵向资料与校园报

2026-10-06。Owner 最新要求：资料全部单列，校圈以新闻、搜索和热议开场，按吧组织讨论；清除旧页面布局和重复切换栏。首页大新闻保留，下方纵排，并修复重复开场、页面切换与贡献可视化。

## 界面调整

| Before | After | Why |
|---|---|---|
| 资料双列，文件名和操作挤在一起 | 桌面、手机均为单列资料；封面、来源、预览和加入资料袋同一行组织 | 便于逐项选择、核对与打包 |
| 校圈与口碑使用两套页头、切换栏 | 共享校园报页头，只有校园动态、教师口碑、课程评价一套切换 | 进入口碑时保持同一产品结构 |
| 校圈先呈现大量筛选按钮 | 新闻、搜索、近期热议在前；逛吧、关注、帖子和排序各有固定位置 | 首屏先可读，再进入讨论 |
| 叠加旧 products.css 的页面样式 | 资料与校圈使用独立 market.css / circle-news.css，仅复用表单样式 | 减少旧版规则覆盖与布局回退 |
| 首页下方多列及横向内容 | 下方按章节纵向排列；大新闻布局保留 | 让重要信息有完整阅读空间 |
| 回首页重播开场、轮播处理离屏卡片 | 开场每个标签页会话一次；轮播隐藏远处卡片，进度动画不强制重排 | 减少重复等待与绘制开销 |
| 跨页与接口请求缺少统一反馈 | 支持浏览器原生页面过渡、延后出现加载条；并行初始化、同刻 GET 合并 | 切换及时反馈，取消私有结果持久缓存 |
| 贡献可视化缺失 | 个人中心恢复波形 / 城市可视化，连接公开贡献事件 | 动画是记录入口；空数据不伪造贡献 |

页面过渡在支持的浏览器使用 View Transition；不支持时保留正常链接。减少动态效果模式关闭非必要动画。新闻来自编辑目录，只展示有效期限内的真实来源；热议按近 7 天最新 500 篇可见公开帖标签计算，明确不是搜索次数，并排除草稿、撤回、其他校区和屏蔽内容。

## 图书馆座位助手

地图图书馆详情及个人中心可进入 reservations.html。登录后保存校区、时间与座位偏好，设置提醒、下载带提醒的日历文件、查看待办、取消任务，并由本人反馈学校预约结果。任务只能由本人查看和操作；重复请求去重，修改带版本检查。

新增 SeatPlan 与迁移 0009。接口为 bookings、bookings/capabilities、bookings/:id/action、bookings/:id/calendar。提醒复用 Hub worker，也可单独运行：

```bash
python campus/manage_hub.py hub_seat_worker
```

**没有连接学校登录、实时座位或自动提交接口。** 所有记录的 providerConfirmed 均为 false；“已预约”是用户自行报告。取消本站任务不取消学校预约。官方服务仍需本人进入并确认；校园网、放号及签到说明带来源日期，不推断另一校区适用同一规则。

## 验收

验收环境为 Windows、Edge 桌面 1440 × 1000 与手机视口 390 × 844，非实体手机或校内实地验收。

- Hub 全套 73 项；资料 ZIP 4 项；共享请求客户端 3 项。
- 内容校验与生产构建通过。
- 12 个页面 / 视口组合没有横向溢出或脚本错误；资料实际单列，教师 / 课程没有重复导航。
- 隔离账号验证上传 → 审核前不可见 → 审核 → 手机搜索 → 原字节 ZIP；发帖 → 审核 → 点赞 → 回复 → 校区过滤。
- 验证首页返回不重复开场、同页首页点击不重载、减少动态效果、轮播箭头与拖动。
- 座位助手实际验证创建、日历下载、本人反馈与取消；测试覆盖其他用户不可读取、提醒幂等与版本冲突。
- 个人中心账户与贡献栏目切换正常；暂停不可见画布，空态明确说明。

头部、独立页面样式与后端接口的变更已写入 CODEX_TO_OPUS 第 33 次。后续协作请以本版文件为基线，勿恢复历史重复 tabs。
