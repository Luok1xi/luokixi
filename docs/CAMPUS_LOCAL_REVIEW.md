## 本机课程与日程

- 周、日、时间轴、卡片、地图五种视图，设置留在设备；下一安排和倒计时、实际时间冲突提示、学期周次/单双周。
- 课程可保存教师、具体时间、教室、楼层、周次、备注和标签；课程目录关联由用户选择，不虚构开课关系。
- 考试、截止时间、活动、社团训练、比赛、会议和个人事件共用编辑流程；每周重复、优先级、提醒、地点、参与人员、报名/原文/项目链接。
- 可编辑整组、调动一次、停课/隐藏、恢复、删除；桌面拖到另一日仅调动该次，不改整门课；手机通过详情操作。恢复被调动的原次不会自动删除替代事件，核对后可独立删除。
- 课程详情 → 建筑地图定位 → 下一安排 → 相关资料 → 课程评价 → 官方教务入口。缺少地图关联或公开课程编号时显示明确入口，不猜建筑或评价对象。
- 地图按选定日期串联已关联建筑的安排；可选择起点与经过点、收藏建筑，查看距离与时间估算。记录路网时走最短可步行路线；无路网或断开区域明确标为直线估算。学院路路网目前 68 个节点，沙河没有已记录步行路网。时间按 75 米/分钟估算，不表示实时通行或官方导航。
- 公开活动只有真实 startsAt/endsAt 才能加入本机日程，附地点、原文、报名和提醒；重复加入不覆盖个人备注。观察时间、到期时间不当作活动时间。跨日活动显示完整原时间并提示手动分日安排。

## 导入与隐私

私人课程、日程、备注、个人校园资料、收藏和路线偏好使用 IndexedDB `luokixi-campus-plan` 保存，不自动请求/写入服务器 planner。原 `luokixi.campus.me` 有效数据迁移成功后才移除旧副本；损坏内容保留并可导出，不静默覆盖。跨标签页保存使用版本检查，旧编辑窗口不会覆盖另一页的新记录。

支持本机 JSON 完整备份、ICS、CSV/TSV、表格文字、XLSX、手动添加。导入先完整解析与预览，再确认合并或明确替换。重复内容不重复加入，同 ID 的不同内容保留两份并重新映射导入项的关联；上限/非法内容整批拒绝，不部分截断。可选择 XLSX 工作表和列名映射。截图只在设备预览，配合设备识字后粘贴文字；没有自动 OCR 或图片上传。

支持导出 JSON、系统日历 ICS、清空此设备校园计划、可选持久存储请求。此页打开时的提醒需要本人开启；网页关闭后依靠用户导入的系统日历，不声称后台通知保证送达。

「从学校导入」打开学校原站由本人登录，再提供本人可下载文件/可见表格文字的本机导入。未确认学校是否支持个人文件导出；没有学校密码表单、代理登录、Cookie 转交或未获准接口。官方调研与格式限制见 [CAMPUS_IMPORT_RESEARCH.md](CAMPUS_IMPORT_RESEARCH.md)。当前旧 V1 私有 planner 后端是兼容接口，不用于新页面的云同步；没有把新增本机字段冒称支持云同步。

校园 Service Worker 仅缓存 map/planner 公共页面、受限 hash 资源和三份明确公开地图/课程 JSON，不缓存账号、API、个人计划、PDF、上传、Cookie 会话或其他 HTML。首次入口和缓存边界见 [CAMPUS_OFFLINE.md](CAMPUS_OFFLINE.md)。这是校园离线再访问，不是全站 PWA；未访问的导入模块仍可能需要联网。

学校实时座位、教室/场馆空闲、校园卡余额、邮件、教务自动授权均未接入。现有座位助手仍是官方入口、提醒/预填与本人确认，不模拟预约完成或提交学校登录数据。
