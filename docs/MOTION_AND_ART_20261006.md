# 首页动效、配图工具与统一图标 · 2026-10-06

本轮沿用 Opus 的新首页排版。Owner 最新要求图标统一一种颜色：已统一石墨灰，不再按功能分颜色。`appIcon()` 同时服务六个快捷入口和“今天”列表，日历按 Asia/Shanghai 显示当前日期。图标为本站原创 SVG，不依赖 SF Symbols 字体或 Apple 图标文件。

## 动效检查

| Before | After | Why |
| --- | --- | --- |
| 开场 SVG 描边逐帧变化，整块遮罩反复重绘 | Logo 静态绘制，整体位移与透明度入场 | 避免每帧重绘整屏 |
| 芯片尚未入完就退出，提前点击会重新显示隐藏元素 | 捕获当前画面后取消旧动画；主动跳过用 180ms 淡出 | 中途操作从当前位置继续 |
| 按住卡片时自动播放可能继续 | 按下就暂停；修正长距离拖动后的目标卡片 | 动画与手势不争抢 |
| 快捷入口用六种彩底 | 统一石墨灰、灰阶细节、相同尺寸与轻按反馈 | 符合 Owner 最新配色要求 |

参考 [Apple Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)、[WebKit WAAPI](https://webkit.org/blog/8343/web-animations-in-webkit/) 和 [Ionic 的开源 iOS 转场](https://github.com/ionic-team/ionic-framework/blob/main/core/src/utils/transition/ios.transition.ts)。Ionic 是第三方 MIT 项目，不是 Apple 官方动画库。本次利用已有浏览器 WAAPI，未引入额外动画框架或复制第三方源码。

同一台本机 Edge，DPR 2、CPU 4 倍减速：冷开场 Paint 桌面 299 → 85，手机视口 302 → 85；整块开场遮罩重绘 112 / 113 → 0。新版还加载了新增专题配图，旧版只有新闻图，因此这是整体回归指标，不能表述成严格单变量对照或保证真实 iPhone 帧率。轮播在 3 次快速切换与 300ms 主线程阻塞下正确落位，无 JS 错误。旧测试脚本自己的 RAF 轮询已从新基准移除，不把测试产生的 RAF 计为网站开销。

## 图片与工具

内置 imagegen 生成 3 张独立母图：学习静物、校园交流、科研光学；复用已有工程装配与机械手创作图。5 个主题配置覆盖 28 个可复用插槽，产生 20 个 WebP 文件，总计 613,618 bytes，最大 146,344 bytes。96px 缩略图供小位置使用；480 / 960 / 原始尺寸供响应式大图使用，不放大原图。

原始母图保留在本机工作目录，没有混进公开目录。接入的成品在 `public/art/generated/`；**完整提示词、来源、用途、审核者**在 `scripts/art-assets.json` 和 `public/art/manifest.json`。这批图由 Codex 检查并按 Owner 指令接入，不宣称 Opus 已逐张审核。

真实新闻沿用报道照片和原文链接；概念图有标识，不能作为具体项目产品照片、教师人像或校园实拍。项目封面优先用户的真实图片，没有才用分类概念图。加载失败回退原有矢量封面；图片解码后显示，避免破图遮住页面。小分类装饰图使用空 alt，避免重复朗读标签。

[配图工具使用说明](ART_PIPELINE.md)：`plan` 找缺图，`ingest` 压缩与缓存，`verify` 校验成品，`generate` 可选连接本机 ComfyUI。普通流程离线；生成模型没有安装或实测，本机 ComfyUI 接口的生命周期以 HTTP mock 验证，不能称为已接通真实模型。内置 imagegen 的使用仍受其自身用量规则约束。
