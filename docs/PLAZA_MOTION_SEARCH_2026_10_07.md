## 可复查测量

同一台机器、Headless Edge；光碟为隔离环境中相同的 80 张合成测试盘，没有写入网站目录。新闻使用现有真实新闻卡。

| 测量 | 原版 | 优化后 |
| --- | ---: | ---: |
| 光碟首次挂载 | 1598.5 ms | 414.4 ms |
| 相同光碟目录再次筛选的同步阻塞 | 1168.1 ms | 0.4 ms |
| 相同画面每帧绘制调用 | 18 | 14 |
| 新闻实际视觉跟手延迟 | 107.8 ms | 51.4 ms |
| 新闻样式计算总耗时（CPU×4、180 帧轨迹） | 119.09 ms | 90.23 ms |

盘面原分辨率仍保留，只把原先集中阻塞的制作工作移到可见范围附近分散执行。快速跨越 35 张盘时，优化后帧间隔 p95 为 8.3 ms、原版 4.3 ms，优化后该段无超过 50 ms 的长任务；这是按需制作的取舍。以上不是所有设备的 FPS 承诺。
