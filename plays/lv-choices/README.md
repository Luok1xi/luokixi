# 《请不要攻略我》· 选项（试玩）

作者：站主。2026-10-11 作者对 Opus 说：暂时公开游戏的一部分，做成 Luokixi 开源广场里能直接玩的一张碟。

- 带了：选项系统 `engine/choices.js`（代码与原版一致，只把注释里的剧情说明换成中性说法，`reject` 默认文字改成“不符合规则”）；`engine/core.js`（引擎核心里选项要用的部分，逐行摘录，去掉了存档、设置、跨周目标记和与人物有关的内容）；`engine/feel.js`（原样）；`engine/sprites-hand.js`（“按 D 的那只手”）；`engine/audio-lite.js`（原版合成器里的六个音效）；`css/choices.css`（从游戏样式表按层叠顺序抽出的选项规则）；`vendor/gsap.min.js`（GSAP 3.12.5，GreenSock 标准免费许可，和游戏用的同一个文件）。
- 外壳 `index.html` `demo.js` `demo.css` 是 Opus 为试玩写的，台词是新写的，不是剧情。`?demo=1` 时自己演。
- 没带：剧情、角色、立绘、背景、音乐、语音、存档。
- 许可：作者授权在 Luokixi 展示和试玩，许可证由作者决定；在那之前转载、再发布请先问作者。
- 注意：这几种选项本身是游戏的机关，推送到公开仓库前请作者再确认一次。
