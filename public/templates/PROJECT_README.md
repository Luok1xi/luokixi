# 项目名称

一句话说清楚：解决什么问题，适合谁使用。

## 项目状态

学习实验 / 可复现原型 / 稳定使用（选择真实状态）

## 作者与来源

作者、团队、所参考项目的链接。注明哪些部分由 AI 辅助完成，以及如何验证。

## 演示与结果

截图或视频、实际测试结果、已知限制。不要上传含密码或个人信息的材料。

## 复现方法

环境版本、安装步骤、运行方式、最小示例和预计时间。
硬件项目补充 BOM、接线图、固件版本、供电与调试说明。

## 文件说明

介绍源码、设计文件、文档、测试分别放在哪里。

## 验证与已知问题

列出测试条件、预期结果、实际结果和还未解决的问题。

## 参与贡献

欢迎帮助的具体事项；第一次贡献可以从哪里开始；如何提交 Issue / Pull Request。

## 许可

为自己有权授权的内容选择许可；代码、图片、数据与第三方依赖可能使用不同许可。
未确定许可时写明“许可未说明”，不要把能下载等同于可自由使用。
